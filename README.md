# SunSense RS – Solar Monitoring System

## Overview

**SunSense RS** is a Python-based solar monitoring system developed as an ENG207 project.

The program monitors solar panel voltage and power under Kuwait's weather conditions. It allows users to generate or load data, analyze readings, and identify normal, warning, and critical states.

The project also explores how environmental factors such as temperature and humidity can affect solar panel performance and efficiency.

## Objectives

- Monitor solar panel voltage and power.
- Generate and load solar monitoring data.
- Analyze solar panel readings.
- Identify normal, warning, and critical states.
- Evaluate the impact of temperature and humidity on solar panel performance.
- Visualize and compare solar monitoring data.

## Features

- Interactive menu-based system.
- Random solar data generation.
- Loading data from a CSV file.
- Data analysis and statistical calculations.
- Comparison of different scenarios.
- Graphical data visualization using Matplotlib.
- Identification of different operating states.
